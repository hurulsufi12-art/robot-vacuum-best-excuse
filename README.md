# The Robot Vacuum's Best Excuse

One line (130 characters, limit 140): a robot vacuum explains why it missed a spot — first person, its own world (bumper, dock), punch at the end.

> I located the crumb, saluted it, and then my bumper held a vote with the chair leg. The chair won. I docked to charge my feelings.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
